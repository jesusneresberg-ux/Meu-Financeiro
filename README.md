# MeuFinanceiro

Aplicativo PWA de controle financeiro pessoal.

## Como testar
Abra `index.html` em um navegador moderno. Para instalar como app/PWA e usar o service worker,
publique os arquivos em HTTPS (GitHub Pages, Netlify, Vercel etc.).

## Recursos incluídos
- Dashboard de saldo, receitas e despesas
- Filtros de período
- Lançamentos de receitas/despesas
- Categorias e contas personalizadas
- Pesquisa de lançamentos
- Gráfico dos últimos 6 meses
- Backup e restauração em JSON
- Dados salvos localmente no navegador
- Layout responsivo para celular e computador
